# Show Pluss

A redesign of the Show Pluss Expo website based on the updated Figma design.

**Stack:** Next.js (App Router), React, TypeScript, and CSS Modules.

Build responsive, accessible, statically generated pages with reusable components. Use Client Components only for interactivity.

## Design foundation

- [Design tokens](Web/src/styles/tokens.css): extracted colors, gradients, typography, spacing, radii, and desktop reference dimensions.
- [Local font declarations](Web/src/styles/fonts.css): Figtree, Plus Jakarta Sans, and Bricolage Grotesque. Font files and their SIL Open Font Licenses are in [public/fonts](Web/public/fonts).
- [Design assets](Web/public/assets): SVG brand symbol, photographs, illustration sheets, and icons.
